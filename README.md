# English Speaking Adventure 4 – Global Success

Ứng dụng luyện nghe - nói tiếng Anh lớp 4 (Global Success), có trợ lý AI Sunny.

## Chạy trên máy
```
npm install
npm run dev
```

## Đưa lên web (GitHub Pages)
1. Push code lên nhánh `main`.
2. Vào **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Mỗi lần push, workflow `Deploy to GitHub Pages` tự build và đăng lên:
   `https://<tên-tài-khoản>.github.io/<tên-repo>/`

Trợ lý Sunny dùng khóa Gemini API do người dùng nhập trong phần Cài đặt (lưu trên trình duyệt).
